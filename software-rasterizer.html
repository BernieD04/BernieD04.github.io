Software Rasterizer in C++

Fall 2026 CS 418, Interactive Computer Graphics

A rasterizer written from scratch in C++ that reproduces the core of the WebGL pipeline in software: it parses a scene description, fills triangles, and writes a PNG.

A machine problem for CS 418 that rebuilds the core of the WebGL pipeline in software, with no GPU involved.

What the program does

Input is a text file of commands. Some set state, such as the vertex position and color buffers; others issue a draw. The program reads the file line by line, updating state as it goes, and rasterizes when it reaches a draw command using whatever state is current at that point. The first line declares the output image: width, height, and filename. The output is a single PNG. It builds and runs through a Makefile.

DDA and scanline

Triangle filling is built from one primitive. A DDA steps between two endpoints and returns the points where a chosen coordinate crosses an integer. Run down the triangle's edges, it gives the two endpoints of each scanline. Run again along each scanline, it gives the pixels.

The DDA interpolates the whole vertex attribute vector rather than position alone, so color and any other per-vertex attribute are carried in the same step.

Perspective divide and viewport transform

Vertices become screen coordinates in two steps. Dividing by w applies the perspective. The viewport transform then maps normalized device coordinates onto the pixel grid.
